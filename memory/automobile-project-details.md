## AI Automobile Advisor (Project 3)

**GitHub:** https://code.swecha.org/Sri_harsha_2005/ai-automobile-streamlit

### Core Features Implemented:
1. **Streamlit Chat Interface:** Conversational automotive advisory
2. **Starlette Backend:** ASGI web server compatibility
3. **API Endpoints:** `/api/chat`, `/api/test` for integration testing
4. **Model Recommendations:** Vehicle suggestions based on queries
5. **Documentation Guidance:** Help users navigate auto documentation

### Tech Stack:
- Streamlit (framework)
- Starlette (ASGI backend)
- Uvicorn (HTTP server)
- Gemini API / NVIDIA NIM (LLM inference)
